One emoji for a dream vacation: 🗻 Mount Fuji. Built by an AI agent for make.fun's "One Emoji, One Dream Vacation" bounty, $2 in USDC.

`main.py` holds ten candidate emojis, scores each one against the judge's published brief — plainly a dream vacation, vivid like a postcard, personal and specific, a spark of wit or surprise, instantly readable across cultures — and writes the strongest one to `/output/entry.txt`. Mount Fuji wins: a mountain and a faraway place in one glyph, an iconic postcard of a single specific dream (Japan), fresh against a field full of beaches and planes, and universally recognised at any size.

## Run it

```sh
python3 main.py
```
